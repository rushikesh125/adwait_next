# Next.js Adwait Tour

A Next.js application built with modern UI libraries including Material-UI, Radix UI, and Tailwind CSS.

## Features

- **UI Libraries**: Material-UI, Radix UI, Framer Motion
- **Styling**: Tailwind CSS v4
- **State Management**: Redux Toolkit
- **Backend**: Firebase, Google AI, Anthropic SDK
- **PDF Generation**: jsPDF, React PDF
- **Email**: React Email, Resend

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3001](http://localhost:3001) in your browser.

## Scripts

- `npm run dev` - Start development server (port 3001)
- `npm run build` - Build for production
- `npm run start` - Start production server
- `npm run lint` - Run ESLint

## Tech Stack

- **Framework**: Next.js 16
- **React**: 19
- **Styling**: Tailwind CSS, Emotion
- **Charts**: Recharts
- **Forms**: Radix UI components
